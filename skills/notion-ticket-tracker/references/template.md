# Ticket database

Default database: https://app.notion.com/p/004425a26dea4373a21c34869a382520

Tracker page: https://app.notion.com/p/3eadd42824ec8106b4d3d03dfbd5285c

Notion data source used when the connection exposes data source IDs: `collection://587ee719-15d8-486b-92fb-d66b814dcfe8`.

Fetch the database before writing. Properties or views may have changed since this reference was written.

| Property | Type | Use |
| --- | --- | --- |
| Summary | Title | Issue title |
| Ticket ID | Unique ID | Generated by Notion; never set manually |
| Jira Key | Text | Original Jira-style key, such as `FOUR-31702` |
| Source File | Text | Original filename or folder-relative path |
| Original Markdown | Files | Exact source `.md` files |
| Supporting Files | Files | Images and non-Markdown source files or verified archives |
| Status | Select | Backlog, To Do, In Progress, In Review, Blocked, Done |
| Type | Select | Bug, Task, Story, Epic |
| Priority | Select | Critical, High, Medium, Low |
| Assignee, Reporter | People | Only when known |
| Project, Sprint | Text | Only when known |
| Labels | Multi-select | Current options include frontend, backend, design, docs |
| Story Points | Number | Only when known |
| Due Date | Date | Only when known |
| Parent, Subtasks | Relations to this database | Explicit ticket hierarchy |
| Created, Updated | System timestamps | Managed by Notion |

The database has **All tickets**, **Board**, **Backlog**, **My tickets**, and **Due dates** views. `All tickets` is the reliable view for imports without a known status; the filtered views may not show those entries.

The default URL points to one private workspace. Another agent still needs its own authenticated Notion access and permission to this database. If the user supplies a different ticket database, honor that target and map the workflow to its live schema.
